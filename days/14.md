# Terraform Static Website on S3 + CloudFront — Day 14 of 30 Days of Terraform

On **Day 14** I built a fully static website stack on AWS using Terraform: an **S3 bucket** for storage, **CloudFront** for CDN delivery, and **Origin Access Control (OAC)** so the bucket stays private. The `backend.tf` also introduces **remote state** via S3 — a critical pattern for real-world team collaboration.

## 1. Remote State Backend (`backend.tf`)

Instead of storing state locally (`terraform.tfstate`), this project sends it to an S3 bucket:

```hcl
terraform {
  backend "s3" {
    bucket = "my-terraform-state-bucket-piyushsachdeva"
    key    = "lessons/day14/terraform.tfstate"
    region = "ap-south-1"
  }
}
```

What this does:

- **`bucket`** — The S3 bucket where state is stored.
- **`key`** — The object path inside the bucket. Using `lessons/day14/` keeps this project's state separate from other days.
- **`region`** — The region of the state bucket.

Remote state is required for:

- **Team collaboration** — Everyone reads/writes the same state.
- **CI/CD pipelines** — The pipeline machine doesn't lose state between runs.
- **Sensitive data** — State isn't sitting on a laptop.

## 2. S3 Bucket for Static Website Hosting

```hcl
resource "aws_s3_bucket" "website" {
  bucket_prefix = var.bucket_prefix
}
```

- **`bucket_prefix`** — Terraform appends random characters to this prefix to guarantee a globally unique bucket name. This avoids naming collisions.
- The bucket itself is **private** — we never make it public. CloudFront serves traffic through a private origin.

---

## 3. Block All Public Access

```hcl
resource "aws_s3_bucket_public_access_block" "website" {
  bucket = aws_s3_bucket.website.id

  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
```

All four public access settings are turned on. This is the default AWS stance: **private by default**.

---

## 4. CloudFront Origin Access Control (OAC)

```hcl
resource "aws_cloudfront_origin_access_control" "oac" {
  name                              = "oac-${var.bucket_prefix}"
  description                       = "OAC for static website"
  origin_access_control_origin_type = "s3"
  signing_behavior                  = "always"
  signing_protocol                  = "sigv4"
}
```

OAC is AWS's **recommended** way to restrict S3 access to CloudFront (it replaces the older Origin Access Identity). CloudFront signs every request with SigV4, and the S3 bucket policy only allows requests signed by this specific distribution.

## 5. S3 Bucket Policy

```hcl
resource "aws_s3_bucket_policy" "website" {
  bucket = aws_s3_bucket.website.id
  depends_on = [aws_s3_bucket_public_access_block.website]

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Sid    = "AllowCloudFrontServicePrincipal"
      Effect = "Allow"
      Principal = {
        Service = "cloudfront.amazonaws.com"
      }
      Action   = "s3:GetObject"
      Resource = "${aws_s3_bucket.website.arn}/*"
      Condition = {
        StringEquals = {
          "AWS:SourceArn" = aws_cloudfront_distribution.s3_distribution.arn
        }
      }
    }]
  })
}
```

Two important details:

- **`depends_on`** — The policy must be attached **after** the public access block is created, otherwise AWS rejects it. `depends_on` forces that ordering even though there's no direct data reference.
- **`jsonencode()`** — Builds the JSON policy document from a Terraform map/object. Much cleaner than a raw JSON string.

## 6. Upload Website Files to S3

```hcl
resource "aws_s3_object" "website_files" {
  for_each = fileset("${path.module}/www", "**/*")

  bucket = aws_s3_bucket.website.id
  key    = each.value
  source = "${path.module}/www/${each.value}"
  etag   = filemd5("${path.module}/www/${each.value}")
  content_type = lookup({
    "html" = "text/html",
    "css"  = "text/css",
    "js"   = "application/javascript",
    "json" = "application/json",
    "png"  = "image/png",
    "jpg"  = "image/jpeg",
    "jpeg" = "image/jpeg",
    "gif"  = "image/gif",
    "svg"  = "image/svg+xml",
    "ico"  = "image/x-icon",
    "txt"  = "text/plain"
  }, split(".", each.value)[length(split(".", each.value)) - 1], "application/octet-stream")
}
```

This is one of the most useful patterns in Terraform. It uses three powerful functions together:

- **`fileset(path, pattern)`** — Returns a list of all files matching the glob pattern in the given directory. `"**/*"` means every file recursively. Terraform creates one `aws_s3_object` per file.
- **`for_each`** — Iterates over the file list, creating one S3 object resource per file.
- **`lookup(map, key, default)`** — Maps file extensions to MIME types. If the extension isn't in the map, it falls back to `application/octet-stream`.
- **`filemd5(path)`** — Computes the MD5 hash of the file, stored in `etag`. This lets Terraform detect when a file changes and re-upload it.

## 7. CloudFront Distribution

```hcl
resource "aws_cloudfront_distribution" "s3_distribution" {
  origin {
    domain_name              = aws_s3_bucket.website.bucket_regional_domain_name
    origin_id                = "S3-${aws_s3_bucket.website.id}"
    origin_access_control_id = aws_cloudfront_origin_access_control.oac.id
  }

  enabled             = true
  is_ipv6_enabled     = true
  default_root_object = "index.html"

  default_cache_behavior {
    allowed_methods  = ["GET", "HEAD"]
    cached_methods   = ["GET", "HEAD"]
    target_origin_id = "S3-${aws_s3_bucket.website.id}"

    forwarded_values {
      query_string = false
      cookies {
        forward = "none"
      }
    }

    viewer_protocol_policy = "redirect-to-https"
    min_ttl                = 0
    default_ttl            = 3600
    max_ttl                = 86400
  }

  price_class = "PriceClass_100"
  restrictions {
    geo_restriction {
      restriction_type = "none"
    }
  }

  viewer_certificate {
    cloudfront_default_certificate = true
  }
}
```

Key decisions:

- **`origin_access_control_id`** — Links the distribution to the OAC we created earlier. This is how CloudFront authenticates to S3.
- **`default_root_object = "index.html"`** — Users visiting the root URL get `index.html`.
- **`allowed_methods = ["GET", "HEAD"]`** — Read-only website. No POST/PUT.
- **`viewer_protocol_policy = "redirect-to-https"`** — Forces HTTPS.
- **`price_class = "PriceClass_100"`** — Cheapest tier (North America + Europe only).

## Connecting the Dots

```
backend.tf ──► Remote state stored in S3
provider.tf ──► AWS in ap-south-1
variables.tf ──► bucket_prefix input

main.tf:
  aws_s3_bucket.website
       │
       ▼
  aws_s3_bucket_public_access_block.website ──► blocks all public access
       │
       ▼
  aws_cloudfront_origin_access_control.oac ──► CloudFront authenticates via OAC
       │
       ▼
  aws_s3_bucket_policy.website ──► Only CloudFront can read bucket (via OAC)
       │
       ▼
  aws_s3_object.website_files ──► Uploads every file from www/ folder
       │
       ▼
  aws_cloudfront_distribution.s3_distribution ──► CDN in front of S3

outputs.tf:
  website_url ──► https://<cloudfront-domain>
  cloudfront_distribution_id
  s3_bucket_name
```

The flow: Terraform provisions the bucket → locks it down → creates the OAC → writes a policy that allows only CloudFront to read → uploads files → creates a CloudFront distribution in front of it. The bucket is never public.

## Best Practices Recap

1. **Use remote state (`backend "s3"`)** for any project beyond personal experiments. It enables collaboration, CI/CD, and protects state from local data loss.
2. **Keep S3 buckets private** — Never make a content bucket public. Use CloudFront + OAC (or OAI) to serve content securely.
3. **Use `origin_access_control` (OAC)** over the older `origin_access_identity` (OAI). OAC uses SigV4 and is AWS's current recommendation.
4. **Use `depends_on`** when Terraform can't infer a dependency — e.g., a bucket policy that must be attached after the public access block.
5. **Use `fileset()` + `for_each`** to upload entire directories instead of writing individual `aws_s3_object` resources.
6. **Use `jsonencode()`** for JSON policy documents instead of raw string interpolation — it's safer and more readable.
7. **Use `filemd5()`** as the S3 object `etag` so Terraform detects file changes and re-uploads efficiently.
8. **Use `lookup()`** for MIME type mapping with a default fallback rather than long `if/else` chains.

## What I Learned

* **S3 remote backend** stores `terraform.tfstate` in S3 instead of the local filesystem, enabling team collaboration and CI/CD workflows.
* **`backend "s3"`** configuration requires a pre-existing S3 bucket and optionally versioning and encryption enabled on that bucket.
* **`aws_s3_bucket_public_access_block`** — All four public access settings should be enabled for private content buckets.
* **CloudFront Origin Access Control (OAC)** — The modern, recommended way to restrict S3 access to CloudFront only. Uses SigV4 signing.
* **`aws_s3_bucket_policy`** — The `jsonencode()` function builds a JSON policy from a Terraform map, avoiding fragile string interpolation.
* **`fileset()`** — Returns a list of files matching a glob pattern in a directory, enabling bulk file operations with `for_each`.
* **`for_each` on `aws_s3_object`** — Creates one S3 object per file in a directory, keeping the configuration DRY.
* **`filemd5()`** — Computes the MD5 hash of a file, stored as the S3 `etag` so Terraform detects changes and re-uploads only modified files.
* **`lookup()` for MIME types** — Maps file extensions to `content_type` with a fallback default for unknown extensions.
* **`depends_on`** — Forces Terraform to wait for a resource to be created before creating another, even when there's no direct attribute reference (e.g., bucket policy after public access block).
* **`bucket_prefix` vs `bucket`** — `bucket_prefix` appends random characters to guarantee global uniqueness. `bucket` requires you to ensure uniqueness yourself.
* **`aws_cloudfront_distribution`** — Configures a CDN with cache behavior, HTTPS enforcement, price class, and geo restrictions in a single resource.
